# 📊 Sistema de Gerenciamento e Processamento de Dados

## 🎯 Objetivo do Projeto
O objetivo deste projeto é resolver a ineficiência no controle manual de registros em um cenário simulado de negócios. Desenvolvido no contexto acadêmico da disciplina de Algoritmos, o sistema substitui processos manuais por uma aplicação em terminal capaz de cadastrar, buscar, ordenar e manipular dados de forma automatizada, garantindo a integridade e a persistência temporária das informações em memória.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java (JDK 17+)
* **Paradigma:** Programação Estruturada e Fundamentos de Orientação a Objetos
* **Ferramentas de Desenvolvimento:** VS Code / Eclipse
* **Controle de Versão:** Git & GitHub

---

## 💡 Aprendizados e Competências Consolidadas
A elaboração desta solução permitiu aplicar na prática os conceitos fundamentais da Engenharia de Software:

* **Lógica e Controle de Fluxo:** Implementação de estruturas condicionais (`if/else`, `switch`) e laços de repetição (`for`, `while`) para controle da execução do programa.
* **Manipulação de Dados:** Uso de vetores (*arrays*) e matrizes para armazenamento e organização eficiente de dados na memória RAM.
* **Validação de Entradas:** Criação de rotinas para sanitização de dados inseridos pelo usuário, prevenindo erros em tempo de execução (*runtime errors*).
* **Modularização:** Organização do código em funções e métodos isolados, facilitando a leitura, manutenção e reutilização da lógica.
* **Pensamento Analítico:** Decomposição de um problema complexo de negócio em pequenos passos lógicos e algoritmos executáveis.
